# SC Soluções Automotivas — site institucional

Site institucional da SC Soluções Automotivas, Sorocaba, SP. Visual clean e responsivo, conteúdo dos serviços, seção de localização, WhatsApp e experiência de vídeo por rolagem.

**Entrada:** `index.html` — HTML auto-contido com animação, fotografias e estilos. Não necessita de servidor de aplicação nem banco de dados. Use hospedagem estática.

**Instalação inicial:** o workflow `.github/workflows/assemble.yml` monta o HTML completo, valida SHA-256 e remove os blocos temporários. Aguarde a ação completar antes de abrir o arquivo.

**Atenção para publicação comercial:** valide os serviços com a cliente e obtenha direitos de uso sobre as imagens aéreas, que podem ter origem no Google Earth. Esta é a versão para aprovação, não necessariamente a versão comercial autorizada.

**Edição futura:** altere a identidade, textos, contatos e conteúdo no `index.html`, preservando o canvas de scroll e os arquivos incorporados.
